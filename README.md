# Minecraft CED Agent

用因果编解码器（CED）驱动的 Minecraft 状态-动作模型。

> **项目状态：设计阶段，尚无实现代码。**
> 本仓库记录的是已经过论证的架构选择、显存预算与感知接口约定，用于指导后续实现，不是已完成系统的说明。

## 目标

在单张 RTX 4080（16 GB）上训练一个 0.8B–1.5B 规模的模型，以 20 Hz（与 Minecraft 逻辑帧率对齐）的频率把游戏状态映射为键鼠动作，并能长期维持空间记忆与任务目标。

约束条件：

- **实时性**：99% 的 tick 不需要输出文字，控制回路必须在毫秒级完成
- **显存**：单卡 16 GB，权重、梯度、优化器状态与激活值全部要装下
- **公平性**：感知接口不得包含透视、夜视等玩家无法获得的信息
