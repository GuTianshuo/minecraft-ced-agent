## 使用

这是附带元数据的 JSON 快照，**不可直接替换整个 `cordis.yml`**。将需要的插件 `config` 按目标 DSH 版本合并到对应插件中；不要覆盖其他插件或本机凭据。所需凭据在目标机器本地安全配置，不写入 Git。没有显式填写的模型参数保持原样，不推测补值。

本机实际环境变量引用名称：`POKE2API_API_KEY`、`GEMINI_AISTUDIO_API_KEY`、`DEEPSEEK_API_KEY`。只包含名称，不包含值。
